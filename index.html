AMBER PHOSPHOR

Pure-black CRT terminal, one amber accent. The single source of truth for every chakri.me site — link theme.chakri.me/tokens.css and inherit it all.

use it

Drop this into your <head> — fonts first, then the tokens.

<!-- Fonts: Press Start 2P (titles) + JetBrains Mono (everything) -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Press+Start+2P&display=block" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;700&display=swap" />

<!-- Amber Phosphor theme tokens -->
<link rel="stylesheet" href="https://theme.chakri.me/tokens.css" />

Every chakri.me site is its own subdomain, so this is a cross-origin link — always the absolute https://theme.chakri.me/tokens.css, which tracks the promoted version. Pin one with https://theme.chakri.me/x.y.z/tokens.css.
